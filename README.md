# dram-edu

6F² DRAM 셀의 동작을 회로도 · 3차원 구조 · 타이밍 다이어그램으로 동시에 따라가는 인터랙티브 시뮬레이터 모음입니다.

**사이트:** https://jjongdi.github.io/dram-edu/

| 페이지 | 내용 |
|---|---|
| [1T1C 셀 동작](https://jjongdi.github.io/dram-edu/1t1c.html) | Read 1 · Read 0 · Write 1 · Write 0 · Refresh, tRCD · tRAS · tRP |
| [Sense Amp 동작](https://jjongdi.github.io/dram-edu/sense-amp.html) | 정상 센싱 · 약한 셀 · SA 미스매치 · retention fail, 센싱 마진 분석 |
| [Row Hammer 불량](https://jjongdi.github.io/dram-edu/row-hammer.html) | D1 · D0 불량 · double-sided · TRR 방어, bit flip 맵 |

각 페이지는 HTML 파일 하나로 되어 있어 내려받아 더블클릭만 해도 열립니다.

시뮬레이터의 수치는 동작 원리를 이해하기 위한 교육용 가정값이며, 실제 공정의 설계값이나 측정값과 다릅니다.
